# Retrospectives

One file per incident, failed live test, or pull request that took more than two
review rounds: `YYYY-MM-DD-short-slug.md`.

Each entry records what happened, what a check up front would have caught, and
the change that now enforces it (a test, a lint rule, a checklist row, or an
`AGENTS.md` rule). An entry without an enforcing change is incomplete.
